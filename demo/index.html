📋 How to Test (Basic)

  4. In one window, click Become Master
  5. Play, pause, or seek — the other window syncs automatically!

🔒 How to Test Access Manager

  1. Enable Access Manager on your keyset in the Admin Portal
  2. Window 1 — Admin (Master):
    1. Toggle Enable Access Manager ON
    2. Select 🔑 Admin mode, enter your Secret Key
    3. Leave Auto-grant on connect checked
    4. Click Connect — a token is auto-granted and applied
    5. Click 📋 Copy Token to copy the token
    6. Click Become Master
  3. Window 2 — Follower:
    1. Toggle Enable Access Manager ON
    2. Select 🎟️ Follower mode
    3. Paste the copied token into the Auth Token field
    4. Click Connect — the follower subscribes with the token
  4. Play, pause, or seek in the Master window — the Follower window syncs!
  5. To test token refresh, set a short TTL (5 min) and wait for it to expire — the Admin window will auto-refresh
